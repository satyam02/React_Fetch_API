# React User Profile Application

A simple React.js application that consumes a REST API built with Node.js and Express and displays user information.

## Project Overview

This project demonstrates how a React frontend communicates with a Node.js backend using a REST API.

The application fetches user details from the backend API and displays:

- User Name
- User Role

### Example Response

```json
{
  "name": "Satyam",
  "role": "Full Stack Developer"
}
